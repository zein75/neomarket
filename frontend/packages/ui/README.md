# `@neomarket/ui`

Framework-light shared primitives for the three apps. Components expose semantic variants and do not contain roles, backend state, secrets or domain CRUD.

The visual contract follows `docs/design-system`: ink `#171717`, paper `#F5F1E8`, surface `#FFFDF7`, cobalt `#2855D9`, lime `#C8F05A`, coral `#FF765C`, 2px borders and hard-edge shadows.
